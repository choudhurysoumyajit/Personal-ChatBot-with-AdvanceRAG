# Personal-ChatBot-with-AdvanceRAG
Chat With Your Files or Use it as a normal personalized ChatBot

This can work in 2 modes
1) If a pdf, txt, csv file is uploaded, the bot will only answer from the document context
2) If there is no document, it will answer as an intelligent chatbot and will answer all questions asked to the best of its knowledge.
